# Anushka Singh — Student Developer Portfolio

A responsive, photo-free static portfolio website displaying the full name **Anushka Singh**.

## Projects
- StudyIQ
- French Vocabulary Quiz
- ApplySense AI (Google Gemini API)

## Preview locally
Open `index.html` in a browser.

## Publish with GitHub Pages
1. Create a public GitHub repository (for example, `anushka-portfolio`).
2. Upload `index.html` to the repository root.
3. In repository Settings → Pages, choose Deploy from a branch.
4. Select the `main` branch and `/ (root)`, then save.
5. GitHub Pages will provide the public website URL.

## Before publishing
- Confirm the exact ApplySense AI live URL still works.
